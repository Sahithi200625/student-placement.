# 🎓 Student Placement Management System

A web-based **Student Placement Management System** designed to help students manage placement opportunities, view job openings, track applications, and access important placement information in one place.

## 🚀 Features

* 👨‍🎓 Student registration and profile management
* 💼 View available job opportunities
* 🔍 Search and filter job listings
* 📝 Apply for placement opportunities
* 📊 Track application status
* 🏢 Company and job details
* 📅 Placement drive information
* 📱 Responsive and user-friendly interface

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Interactive functionality
